# meta-hypertools Tool Suites

For a **compact overview** and links into this folder, see **[../TOOLS.md](../TOOLS.md)**.

meta-hypertools is organized into modular tool suites, each handling a specific domain of the MCP ecosystem.

## 🧰 Available Suites

### [Server Management](server-management.md)
Lifecycle control for MCP servers: start, stop, restart, and monitor processes with PID tracking and resource usage.

### [Tool Execution](tool-execution.md)
Remote invocation engine: execute tools across connected MCP servers with parameter validation and history tracking.

### [Repository Intelligence](repository-intelligence.md)
Deep codebase analysis: health scoring, dependency auditing, code quality metrics, and structure analysis.

### [Client Management](client-management.md)
Multi-IDE ecosystem control: manage configurations for Claude, Cursor, Windsurf, Zed, and Antigravity with backup safety.

### [Diagnostics](diagnostics.md)
System health and safety: Unicode crash prevention (EmojiBuster), PowerShell validation, and crash protection.

### [Toolchains](toolchains.md)
Preset management: Curate collections of MCP servers into toolchains and rapidly deploy them to your target IDE.


### [Analysis](analysis.md)
Advanced insights: Runt Analyzer for repo upgrades, SOTA compliance checking, and metadata extraction.

### [Discovery](discovery.md)
Ecosystem visualization: automatic server scanning, client integration checks, and verified connection auditing.

### [Scaffolding](scaffolding.md)
Project generation: create enterprise-grade MCP servers, fullstack web apps, landing pages, and games.

### [Token Analysis](token-analysis.md)
LLM context optimization: language-aware token counting, context limit estimation, and distribution analysis.

### [Repository Packing](repo-packing.md)
AI-ready export: consolidate repositories into XML, Markdown, or JSON formats optimized for LLM consumption.

### [Repository Inspiration](repo-inspiration.md)
Remote GitHub study without clone: filtered trees, smart file pick, architecture prompts (`inspire_repo_*`). Native port of [Repomuse](https://www.npmjs.com/package/repomuse) (MIT).

### [Meta / fleet dev](meta-dev.md)
Fleet health probes, MASTER config snippets, diffs, FastMCP surface audits, and local hygiene checks (`meta_dev` suite).

### [Demo capture](demo-capture.md)
Remote webapp demo pipeline: `demo_ops` — Playwright screenshots/video walkthrough + optional Remotion MP4 render (`demo_capture` suite).
